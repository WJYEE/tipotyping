# OA 및 AI 활용 역량 — 학습 정리

> 성격: 제공된 KB-Bridge 메모와 문제 주제를 바탕으로 재구성한 복습용 요약. 원본 강의의 완전한 전사본은 아님.

## 학습 목표
업무 생산성과 AI 리터러시

## 핵심 내용
생성형 AI의 출력은 확률적 생성 결과이므로 정확성과 출처를 별도로 검증한다. 프롬프트에는 목적·맥락·입력·제약·출력 형식·검증 기준을 명시한다. OA 자동화는 반복적이고 규칙이 명확한 작업부터 시작한다.

## 이 카테고리에서 다루는 문제 주제
- 생성형 AI
- 프롬프트
- OA
- AI 활용
- 검색
- 업무효율

## 적용·실습 흐름
프롬프트 설계 → 결과 검토 → 근거 확인 → 개선; 민감정보 입력 및 외부 공유 전 보안 확인

## 헷갈리는 부분
환각과 단순 오타, 자동화와 의사결정 대체, API 키와 서비스 계정 권한을 구별한다.

## 복습법
1. 핵심 용어를 한 문장으로 설명한다.
2. 원문 문제를 풀고 오답 원인을 기록한다.
3. 각 문항의 **[파생질문]**으로 조건이 바뀌었을 때도 설명할 수 있는지 확인한다.
4. 해당 주제를 실습이나 금융 업무 사례로 연결한다.
