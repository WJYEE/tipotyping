# AI 기반 데이터 분석 — 학습 정리

> 성격: 제공된 KB-Bridge 메모와 문제 주제를 바탕으로 재구성한 복습용 요약. 원본 강의의 완전한 전사본은 아님.

## 학습 목표
AI 활용 데이터 분석과 금융 IT

## 핵심 내용
데이터 분석은 문제 정의→데이터 이해→품질 점검→분석/모델링→검증→의사결정의 순서로 진행한다. ERD는 엔터티와 관계를 나타내며 1:N·N:M 구조를 구별한다. Text-to-SQL과 MCP는 데이터 접근을 도울 수 있지만 권한·쿼리 검증이 필요하다.

## 이 카테고리에서 다루는 문제 주제
- 금융 IT
- DDD
- Text-to-SQL
- MCP
- API
- 분석
- 검증

## 적용·실습 흐름
금융 업무 질문→필요 테이블 식별→읽기 전용 SQL 생성→결과 검증→인사이트·근거 제시

## 헷갈리는 부분
상관관계와 인과관계, 데이터 접근 권한과 결과 정확성, 계정계·채널계·정보계의 역할을 구별한다.

## 복습법
1. 핵심 용어를 한 문장으로 설명한다.
2. 원문 문제를 풀고 오답 원인을 기록한다.
3. 각 문항의 **[파생질문]**으로 조건이 바뀌었을 때도 설명할 수 있는지 확인한다.
4. 해당 주제를 실습이나 금융 업무 사례로 연결한다.
