# 자격증 · SQLD — 학습 정리

> 성격: 제공된 KB-Bridge 메모와 문제 주제를 바탕으로 재구성한 복습용 요약. 원본 강의의 완전한 전사본은 아님.

## 학습 목표
SQLD 학습 체계

## 핵심 내용
데이터 모델링(엔터티·속성·관계·정규화)과 SQL 기본/활용(JOIN·서브쿼리·집계·윈도우 함수)을 반복한다. 문제 풀이 뒤 오답 원인을 개념·문법·NULL 처리로 분류한다.

## 이 카테고리에서 다루는 문제 주제
- 모델링
- SQL 기본
- SQL 활용
- 최적화

## 적용·실습 흐름
ERD를 그린 뒤 테이블 생성→샘플 데이터 입력→SQL 실행 결과로 검증

## 헷갈리는 부분
NULL 비교, 집계 대상, 조인 후 중복행, 윈도우 함수의 PARTITION BY를 특히 점검한다.

## 복습법
1. 핵심 용어를 한 문장으로 설명한다.
2. 원문 문제를 풀고 오답 원인을 기록한다.
3. 각 문항의 **[파생질문]**으로 조건이 바뀌었을 때도 설명할 수 있는지 확인한다.
4. 해당 주제를 실습이나 금융 업무 사례로 연결한다.
