# SQL — 학습 정리

> 성격: 제공된 KB-Bridge 메모와 문제 주제를 바탕으로 재구성한 복습용 요약. 원본 강의의 완전한 전사본은 아님.

## 학습 목표
SQL 조회·집계·분석

## 핵심 내용
SELECT/WHERE/GROUP BY/HAVING/ORDER BY의 역할과 논리적 처리 순서를 구분한다. JOIN은 테이블 관계와 카디널리티를 고려하고, 윈도우 함수는 행을 유지한 채 순위·누적·비교 값을 만든다.

## 이 카테고리에서 다루는 문제 주제
- 기초
- 중급
- 심화

## 적용·실습 흐름
Sakila 등의 연습 DB로 고객·주문·상품 JOIN→그룹 집계→Top-N 추출; 인덱스와 실행계획은 성능 분석에 사용

## 헷갈리는 부분
NULL이 포함된 NOT IN, LEFT JOIN 뒤 COUNT(*), WHERE와 HAVING, ROW_NUMBER와 RANK를 비교한다.

## 복습법
1. 핵심 용어를 한 문장으로 설명한다.
2. 원문 문제를 풀고 오답 원인을 기록한다.
3. 각 문항의 **[파생질문]**으로 조건이 바뀌었을 때도 설명할 수 있는지 확인한다.
4. 해당 주제를 실습이나 금융 업무 사례로 연결한다.
