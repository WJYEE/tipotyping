# 대시보드·기초통계 — 학습 정리

> 성격: 제공된 KB-Bridge 메모와 문제 주제를 바탕으로 재구성한 복습용 요약. 원본 강의의 완전한 전사본은 아님.

## 학습 목표
기초통계와 Power BI 대시보드

## 핵심 내용
평균·중앙값·분산·표준편차·결측치 처리의 해석을 익힌다. 대시보드는 사용자·결정·핵심 KPI를 먼저 정의한 뒤 차트·필터·드릴다운을 설계한다. Power BI는 데이터 모델 관계와 측정값의 필터 컨텍스트가 중요하다.

## 이 카테고리에서 다루는 문제 주제
- Power BI
- 모델링
- KPI
- 시각화
- 기초통계
- 설계

## 적용·실습 흐름
금융 KPI 대시보드: 기업/기간 선택→매출·이익 변화→이상치 강조→근거 원문 링크; 차트 3개 이내로 시작

## 헷갈리는 부분
표본 수와 비율, 평균과 중앙값, 합계와 평균의 집계 수준, 시각적 상관과 인과를 구별한다.

## 복습법
1. 핵심 용어를 한 문장으로 설명한다.
2. 원문 문제를 풀고 오답 원인을 기록한다.
3. 각 문항의 **[파생질문]**으로 조건이 바뀌었을 때도 설명할 수 있는지 확인한다.
4. 해당 주제를 실습이나 금융 업무 사례로 연결한다.
