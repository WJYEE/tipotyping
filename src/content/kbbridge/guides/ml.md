# 머신러닝 — 학습 정리

> 성격: 제공된 KB-Bridge 메모와 문제 주제를 바탕으로 재구성한 복습용 요약. 원본 강의의 완전한 전사본은 아님.

## 학습 목표
머신러닝 기본 개념과 평가

## 핵심 내용
지도학습은 정답 레이블로 학습하고 비지도학습은 군집·차원축소 등의 구조를 찾는다. 학습·검증·테스트 분리와 누수 방지가 핵심이다. 분류는 Precision·Recall·F1·ROC-AUC, 회귀는 MAE·RMSE·R²를 목적에 맞게 해석한다.

## 이 카테고리에서 다루는 문제 주제
- 기초
- 분류 평가
- 회귀 평가
- 데이터 누수
- 과적합
- 교차검증
- 특성
- 트리
- 모델링

## 적용·실습 흐름
문제/타깃 정의→분할→전처리 fit은 학습에만→모델 학습→검증→오류 분석

## 헷갈리는 부분
불균형 데이터에서 Accuracy 착시, 임계값과 정밀도-재현율 트레이드오프, 과적합과 데이터 누수를 구별한다.

## 복습법
1. 핵심 용어를 한 문장으로 설명한다.
2. 원문 문제를 풀고 오답 원인을 기록한다.
3. 각 문항의 **[파생질문]**으로 조건이 바뀌었을 때도 설명할 수 있는지 확인한다.
4. 해당 주제를 실습이나 금융 업무 사례로 연결한다.
