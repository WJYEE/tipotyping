# AI 에이전트 활용 기초 — 학습 정리

> 성격: 제공된 KB-Bridge 메모와 문제 주제를 바탕으로 재구성한 복습용 요약. 원본 강의의 완전한 전사본은 아님.

## 학습 목표
AI Agent와 n8n 자동화

## 핵심 내용
워크플로우는 트리거·데이터 수집·변환·조건 분기·전송·예외처리로 구성한다. n8n의 Loop Over Items, Merge, IF, Sort, Limit, Aggregate는 각기 다른 데이터 처리 역할을 수행한다. RAG는 외부 문서를 검색해 생성 답변의 근거로 사용하는 방식이며 정답을 보장하지 않는다.

- 기초
- n8n
- JSON
- API
- RAG
- 보안
- 운영

## 적용·실습 흐름
RSS→정제→중복 제거→Gmail 발송; 금융상품 KPI 변화→임계값 판정→근거와 함께 알림; 문서 수집→청킹→임베딩→검색→답변

## 헷갈리는 부분
JSON 문자열과 객체, 인증과 권한, 검색 실패와 모델 환각, 노드 재실행 시 중복 발송을 구별한다.

## 복습법
1. 핵심 용어를 한 문장으로 설명한다.
2. 원문 문제를 풀고 오답 원인을 기록한다.
3. 각 문항의 **[파생질문]**으로 조건이 바뀌었을 때도 설명할 수 있는지 확인한다.
4. 해당 주제를 실습이나 금융 업무 사례로 연결한다.
