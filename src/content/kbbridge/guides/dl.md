# 딥러닝 — 학습 정리

> 성격: 제공된 KB-Bridge 메모와 문제 주제를 바탕으로 재구성한 복습용 요약. 원본 강의의 완전한 전사본은 아님.

## 학습 목표
딥러닝과 임베딩

## 핵심 내용
신경망은 입력·은닉·출력층과 가중치 학습으로 패턴을 표현한다. 역전파·경사하강법, 배치·에포크·학습률을 이해한다. 시퀀스에는 RNN/LSTM/GRU, 텍스트 검색에는 임베딩과 유사도 개념을 적용한다.

## 이 카테고리에서 다루는 문제 주제
- 기초
- 학습
- 과적합
- CNN
- RNN
- LSTM
- Transformer
- Embedding
- 평가

## 적용·실습 흐름
데이터 분할→베이스라인→신경망 학습→검증 손실 비교→과적합 대응

## 헷갈리는 부분
학습 성능과 일반화 성능, 임베딩 유사도와 사실 여부, 모델 복잡도와 데이터 규모를 구별한다.

## 복습법
1. 핵심 용어를 한 문장으로 설명한다.
2. 원문 문제를 풀고 오답 원인을 기록한다.
3. 각 문항의 **[파생질문]**으로 조건이 바뀌었을 때도 설명할 수 있는지 확인한다.
4. 해당 주제를 실습이나 금융 업무 사례로 연결한다.
