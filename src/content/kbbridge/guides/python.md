> 성격: 제공된 KB-Bridge 메모와 문제 주제를 바탕으로 재구성한 복습용 요약. 원본 강의의 완전한 전사본은 아님.

## 학습 목표
Python 기본 문법과 데이터 처리

## 핵심 내용
자료형(list·tuple·dict·set), 조건문, 반복문, 함수, 슬라이싱, 컴프리헨션, 예외처리부터 시작한다. Pandas는 필터링·결측치·groupby·merge·인덱스 처리, NumPy는 벡터화 연산을 익힌다.

## 적용·실습 흐름
입력 데이터→자료형 검사→필터링→집계→검증; 문제를 작은 함수로 나눠 테스트

## 헷갈리는 부분
가변 기본 인자, 얕은 복사, and/or와 |/&, reset_index(drop=True), isdigit()의 한계를 주의한다.

## 복습법
1. 핵심 용어를 한 문장으로 설명한다.
2. 원문 문제를 풀고 오답 원인을 기록한다.
3. 각 문항의 **[파생질문]**으로 조건이 바뀌었을 때도 설명할 수 있는지 확인한다.
4. 해당 주제를 실습이나 금융 업무 사례로 연결한다.
